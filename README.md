# Carteira de Investimentos

Este projeto teve como objeto criar uma simulação de carteira de investimentos para fins educativos.

---

## Sobre o projeto

O projeto foi criado para a disciplina de Algoritmos e Pensamento Computacional, 2º semestre, noturno, Centro Universitário Braz Cubas.
Seu propósito é a educação acerca da inclusão financeira, de acordo com a ODS 8, meta 8.10, da ONU.

---

## Público-alvo

Qualquer pessoa que não tenha conhecimentos básico sobre como funciona uma carteira de investimentos e tenha curiosidade sobre.

## Funcionalidades

- [x] Cadastrar ativos
- [x] Listar ativos cadastrados
- [x] Calcular valor total dos ativos
- [x] Calcular a rentabilidade total dos ativos
- [x] Ordenação de rentabilidade do melhor para o pior
- [x] Simulador de aplicação em diferentes rendimentos
- [x] Relatório final que resume as funções anteriores

---
